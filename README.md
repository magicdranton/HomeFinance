# HomeFinance
**Desktop app that helps monitoring personal finance transactions

## Key features:
* Quick transactions download from top banks CSV formats & GMail notes using POP3
* Trans auto-merge (in/out trans as a single transaction between Accounts)
* Running total by each Account by date
* Reports: 
** In/Out totals by Categories in  specified period vs planned amounts
** Amount remainders by Account
** Import errors logging

## Technologies used:
* .NET Framework 4.7.2, WinForms
* SQLite as a Database
* Entity Framework 6
* SQL Reporting Services Report design format
* UnitTests
